Stage 3 security research

When AUTO is ON, the app attempts public RugCheck reports for limited candidates (up to 4 per refresh); while OFF, use the Scan risk button for any candidate you want to examine. If RugCheck blocks browser requests, requires a key, or is rate-limited, the app displays UNVERIFIED and never assumes PASS. Never paste API keys or wallet seed phrases into a public GitHub Pages site. Tokens with no reported flags and minimum research fields may be opened for VIRTUAL PAPER TESTS ONLY. They remain unverified, not independently audited. Unknown reports and dangerous findings block paper BUY; there is no real trading.

Discovery uses up to 4 recent-pool pages each refresh (if available). Token security is not automatically guaranteed by the scanner. You can open RugCheck externally to see full details.

Data and privacy

No real account connection. No wallet keys or passwords. Portfolio, settings, watchlist and trades are saved in this browser's local storage on this device only. Clearing site data or switching browsers removes your saved account. There is no backend, alert service, or background trading. Auto IQ only runs when AUTO is ON and the browser is active; when OFF it does not scan or close positions. It never runs in background.

Feeds: GeckoTerminal and DEX Screener. Best-effort reports: RugCheck API · RugCheck manual review.
